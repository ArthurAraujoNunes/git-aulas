# ☕ Site de Cafeteria

Um site moderno e acolhedor desenvolvido para apresentar uma cafeteria, seus produtos e sua identidade visual.

## 📖 Sobre o projeto

Este projeto tem como objetivo criar uma experiência digital agradável para os clientes de uma cafeteria, permitindo conhecer o ambiente, consultar o cardápio e descobrir os principais produtos oferecidos.

A proposta combina **design moderno, simplicidade e uma atmosfera aconchegante**, transmitindo pela interface a mesma sensação de uma boa experiência em uma cafeteria.

## ✨ Funcionalidades

- 🏠 Página inicial com apresentação da cafeteria
- ☕ Destaque para cafés e bebidas
- 🍰 Seção de produtos e acompanhamentos
- 📋 Cardápio
- 📍 Informações sobre localização e horário de funcionamento
- 📱 Design responsivo para computadores, tablets e celulares
- 📞 Informações de contato
- 📸 Galeria de imagens

## 🎨 Objetivo visual

A identidade do site busca transmitir:

- Aconchego
- Elegância
- Simplicidade
- Qualidade
- Experiência artesanal

A paleta de cores pode utilizar tons inspirados no café, como **marrom, bege, creme e caramelo**, criando uma identidade visual quente e convidativa.

## 🚀 Projeto

Este projeto está sendo desenvolvido como uma solução web para uma cafeteria, podendo posteriormente receber funcionalidades como:

- Sistema de pedidos online
- Integração com WhatsApp
- Reservas de mesas
- Programa de fidelidade
- Área administrativa
- Integração com redes sociais
